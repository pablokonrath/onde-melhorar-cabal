# Onde Melhorar · Bestiário Cabal

Ferramenta de uma página só (`index.html`) para o Cabal Online BR. Você digita os status do seu personagem, escolhe um chefe ou monstro de uma DG de nível 180+ e a página mostra:

- quais atributos mais aumentam o seu dano contra aquele alvo, em ordem;
- as metas objetivas (acerto contra a evasão, perfuração contra a defesa, ignorar resistências, bloqueio, redução de dano);
- o maior gargalo de cada alvo da DG inteira.

## Como usar
Abra `index.html` no navegador, ou publique com GitHub Pages (Settings → Pages → branch `main`, pasta `/root`). Não precisa de servidor nem de instalação. Os números ficam salvos só no navegador de quem usa.

## Avisos
- A fórmula de dano do jogo não é pública. O modelo é uma estimativa para **comparar atributos entre si**, não para prever o dano exato.
- O bloqueio do alvo aparece como meta, mas não entra no cálculo do ranking.
- Os dados dos bosses vêm do bestiário em neogames.online e podem ter erros. Confira no jogo.
- Projeto de fã, sem ligação com a desenvolvedora do jogo nem com o site da fonte dos dados.
